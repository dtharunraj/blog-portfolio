# Blog Portfolio 📝

A full-stack blog application built using React.js, Node.js, Express.js, MongoDB, and Firebase Authentication.

### Features
- Admin Login
- Create and View Blogs
- Like Blog Posts
- Search Blogs
- MongoDB Integration

### Tech Stack
React.js • Node.js • Express.js • MongoDB • Firebase
